Предпросмотр

ЛКМ — поворот, колесо — масштаб. Клик по боксу выбирает часть, поля в панели меняют её размер и положение, двойной клик по корпусу добавляет бокс. Перетаскивание мышью коллайдер не двигает. Зелёным показан коллайдер, жёлтым — выбранная часть.

Размеры модели

Габариты берутся из манифеста модели (public/models/<id>.json). Меняются только пересборкой ассета, здесь — справочно. 1 единица = 1 м; в скобках — сантиметры.

Строится по треугольникам меша: объём модели раскладывается на боксы, они не выходят за корпус. Детализация — число вокселей по длинной стороне, лимит — сколько боксов оставить (движок принимает до 32). Настройки хранятся в public/models/<id>.physics.json.

В предпросмотре: клик по боксу — выбрать часть, двойной клик по корпусу — добавить бокс в точку попадания. Положение и размеры меняются только полями — мышью коллайдер не перетаскивается. Ctrl+Z — отменить, Delete — удалить выбранную часть.

Значения — в локальных единицах модели: в сцене они умножаются на масштаб объекта. Эти настройки подставляются при добавлении модели в сцену; у уже добавленных объектов коллайдер правится в их инспекторе.
