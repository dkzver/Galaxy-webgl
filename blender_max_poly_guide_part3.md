## Шаг 7: Материалы и шейдеры для High-Poly

### Cycles Materials:
- **Principled BSDF**:
  - Metallic: 0.1-0.3 для металла корабля
  - Roughness: 0.6-0.8 (матовой), 0.2-0.4 (блестящих)
  - Normal Map: Имитация мелких деталей без дополнительной геометрии

### Subsurface Scattering:
- Для пластиковых деталей, стекол, иллюминации
- Weight: 0.3-0.7, Color: светло-голубой/розовый

### Vertex Paint:
- Ручная окраска worn areas, water stains, paint chipping
- Mode: Vertex Paint, используйте кисти для повреждений

## Шаг 8: Рендер высокопoly модели

### Cycles настройки:
- Samples: 512+ (для финального рендера)
- Light Paths: Max Bounces = 16
- Denoiser: AI Denoiser (включен)
- Bloom: Осторожно

### Свет:
- **HDRI World Environment**: Качественная текстурная карта
- **Area lights**: Для emphasis key features
- **Sun/Sky**: Directional light, копируя освещение с reference

### Eevee Next (если доступно):
- Shader Quality: Very High
- Reflection Quality: High
- Screen Space Reflections: On

## Шаг 9: Финальная проверка

1. Переключайтесь между всеми 5 камерами - проверяйте детали с каждого ракурса
2. Убедитесь в согласованности масштаба между видами
3. Проверьте нормали: `Shift+N` → "Recalculate Outside"
4. Тестовый рендер: `F12` → проверьте на наличие артефактов
