# Виджеты прицела GalaxyDemo

Сейчас в игре два виджета:

| Виджет | Объект | Скрипт-роль | Что делает |
|--------|--------|-------------|------------|
| **Перекрестие** | `type: "reticle"`, `Прицел` | `reticle.js` | висит в точке прицела и меняет цвет, когда луч упирается в модель |
| **Круг** | `type: "reticle"`, `Курсор` | `cursor.js` | висит в экранной точке мыши |

Объект — это данные и дизайн, роль — поведение, движок — общие правила и
позиционирование. Нет объекта или роли — виджета нет; для курсора в этом
случае работает системный указатель.

## Файлы

| Файл | Назначение |
|------|------------|
| `public/js/reticles.js` | умолчания, нормализация, роли слоёв, загрузка SVG |
| `public/js/reticle-view.js` | хост: монтирование дизайна, позиция, классы состояний |
| `public/hud/reticle.css` | общие правила: анимации ролей, цвета |
| `public/hud/reticles/*.svg` | дизайны: `crosshair.svg`, `circle.svg` |
| `public/scripts/reticles/*.js` | дизайн-скрипты: свои параметры + дескриптор |
| `public/scripts/reticle.js` | роль «перекрестие»: точка прицела + цвет по лучу |
| `public/scripts/target.js` | контроллер на `weapon-target`: ссылки на игрока и прицел, линия и попадание |
| `public/scripts/cursor.js` | роль «круг»: проверяет ссылку сцены и показывает виджет |

## Как включается

1. На `weapon-target` (в префабе корабля) висит `target.js` с полями
   **«Игрок»** и **«Прицел»** — он строит линию от игрока и публикует
   `target.reticle`, `target.point`, `target.state`.
2. На объекте `reticle` есть дизайн-скрипт (`reticles/crosshair.js` или
   `reticles/circle.js`) — он задаёт форму и параметры.
3. На нём же есть роль: `reticle.js` или `cursor.js`. В инспекторе это поля
   **«дизайн»** и **«роль»**; они просто заменяют соответствующий скрипт.
4. Прицел рисуется только если ссылка `target.reticle` с `weapon-target`
   указывает на него.
5. В скрипте сцены (`first-screen.js`) поле **«Курсор»** ссылается на объект-курсор:
   пусто — работает системный указатель, задано — движок показывает виджет.

## Общие правила: роли слоёв SVG

Движок понимает разметку по `data-role`:

| Роль | Что делает движок |
|------|-------------------|
| `outer` | вращение, период `--wr-spin` |
| `mid` | обратное вращение, период `--wr-counter` |
| `scan` | бегущая дуга, период `--wr-scan` |
| `core` | «дыхание» ядра, период `--wr-breathe` |
| `progress-group` / `progress` | кольцо прогресса (зарезервировано под курсор) |

Цвет наследуется через `currentColor`, поэтому один SVG работает со всеми
состояниями.

## Цвета

```json
"reticle": { "size": 34, "color": "#68daff", "aimColor": "#ffc857" }
```

- покой — `color`;
- наведение на модель — `aimed`, цвет `aimColor`.

## Логика перекрестия

`target.js` на `weapon-target` каждый кадр:

1. берёт объект игрока из поля «Игрок»; без ссылки линия не строится;
2. берёт мировую точку прицела у движка (`api.target.aim()`), она считается
   как `нос + forward × 500` и следует за кораблём;
3. строит луч от позиции игрока к этой точке; луч **бесконечный**;
4. проверяет его против моделей сцены (`model.bounds`, AABB), исключая свой
   корабль;
5. публикует `target.state = { visible, aimed }` и `target.point`.

`reticle.js` на объекте-прицеле только проверяет ссылку `target.reticle`
и рисует виджет с цветом `aimColor`, когда `aimed` истинно.

Другой логики у прицела нет: ни прогресса, ни вспышек, ни проверки оружия.

## Курсор

Ссылка живёт в params скрипта сцены: `first-screen.js` → `cursor: "reticle-cursor-1"`.
В редакторе это поле **«Курсор»** в секции «Скрипт сцены» у объекта «Сцена».

* поле пустое — системный указатель, виджета нет;
* поле задано — движок скрывает системный курсор и ставит виджет в точку мыши;
* если у объекта есть роль `cursor.js`, она проверяет ссылку и рисует сама;
* если роли нет, движок показывает объект напрямую (размер и цвета из блока
  `reticle`, форма — из дизайн-скрипта).

Логику курсора (состояния, прогресс, поведение) вернём отдельным шагом; кольцо
`progress` в `circle.svg` для этого уже размечено.

## Как добавить или заменить

1. Правый клик по дереву → **«Добавить прицел»**.
2. В инспекторе выберите **дизайн** (`crosshair` / `circle`) и **роль**
   (`reticle.js` / `cursor.js`).
3. Для прицела: на `weapon-target` в `target.js` выберите игрока и этот объект.
4. Для курсора: в скрипте сцены `first-screen.js` поле **«Курсор»** — выберите объект.
5. Трансформ объекта не используется: положение задаёт движок.

Дизайн можно сменить в любой момент: параметры скрипта появятся в секции
«Скрипты», а предпросмотр в инспекторе обновится.

## Canvas-дизайн

Хост поддерживает `kind: 'canvas'`: скрипт возвращает `draw(ctx, frame)`
и получает `{ size, time, progress, color, aimed, pulse }`. Готовых
canvas-виджетов сейчас нет — только SVG.

## Отладка

```js
__galaxy.reticle                 // хост прицела
__galaxy.cursorReticle           // хост курсора
__galaxy.targets                 // api.target: show/hide/cursor/aim
__galaxy.scripts.errors          // ошибки скриптов
```

Если перекрестие не появляется: у объекта-прицела должна быть роль
`reticle.js` и дизайн `reticles/*.js`; если не меняет цвет — проверьте, что
у модели есть `model.bounds` и она не является частью корабля игрока.
