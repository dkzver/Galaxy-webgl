# Материалы как данные

Материал — JSON-ассет в `public/materials/<id>.material.json`. В нём: id,
шейдер, режим смешивания и схема параметров. Редактор строит поля из `params`,
движок берёт значения из `uniforms`. Пока это только данные: рендер по
материалам — следующий этап.

## Формат

```json
{
  "id": "shield",
  "title": "Энергетический щит",
  "shader": "shield",
  "blend": "additive",
  "depthWrite": false,
  "params": {
    "color": { "type": "color", "label": "Цвет", "default": "#59d8ff" },
    "base": { "type": "number", "label": "Прозрачность", "default": 0.06, "min": 0, "max": 1, "step": 0.01 }
  },
  "uniforms": { "color": "#59d8ff", "base": 0.06 }
}
```

| Поле | Что задаёт |
|---|---|
| `shader` | id программы: `mesh` (обычный), `shield` (щит); позже `glass`, `hologram` |
| `blend` | `opaque`, `alpha`, `additive` |
| `depthWrite` | писать ли глубину (для прозрачного — `false`) |
| `params` | схема для инспектора: `color`, `number` (с `min`/`max`/`step`), `text` |
| `uniforms` | значения; при загрузке клампятся по схеме, мусор заменяется дефолтом |

`uniforms` может не быть — тогда всё возьмётся из `params.default`.

## API

| Метод | Что делает |
|---|---|
| `GET /api/materials` | список: id, title, shader, blend, uniforms |
| `GET /api/material/<id>` | файл материала |
| `POST /api/material/<id>` | сохранить (тело — материал или `{ material }`) |

## Щит

`public/materials/shield.material.json` — параметры эффекта: цвет оболочки,
цвет попадания, базовая прозрачность, степень френеля, радиус пятна, масштаб
гексагональной кожи (`hexScale`, по умолчанию 4 ячейки/м), время пятна и кольца.

### Как подключить

В инспекторе объекта модели выберите материал; в JSON это поле `materialId`:

```json
{
  "id": "shield-1", "type": "model",
  "asset": "corinth-cargo-transported-shield",
  "materialId": "shield",
  "body": { "kind": "static", "collider": { "shape": "sphere", "radius": 4.2 } }
}
```

Движок берёт материал из `GET /api/materials` и рисует сущность программой
из поля `shader`. Для `shield`: гексагональная «кожа», видимая только вокруг попаданий, а в точках
попаданий — белое ядро, гексагональное пятно и расходящееся кольцо (до четырёх
одновременно). Пятно рисуется вторым
проходом без теста глубины: меш щита почти совпадает с обшивкой, иначе глубина
съедала бы её.

Попадания приходят из `projectile.hit` — `public/scripts/ship/shield.js` копит
их в `entity.shieldHits`, рендер читает этот массив.

**Как сделать меш щита:** [`docs/shield-mesh.md`](shield-mesh.md) — габариты, коллайдер,
данные сцены и чек-лист.

### Окно материала

`material-editor.html?material=<id>` — предпросмотр сферы и поля из схемы
`params`: цвет оболочки и попадания, прозрачность, френель, радиус пятна,
гекс, времена. Кнопка **«Тест попадания»** зажигает пятно на сфере, **«Сохранить»**
пишет тот же `<id>.material.json` (Ctrl+S).

В редакторе сцены у объекта с материалом есть кнопки **«Редактировать материал»**
и **«Тест попадания»** — вторая показывает пятно прямо во вьюпорте (попадания
стареют в кадре редактора).

Выбор в инспекторе работает для любого ассета из `public/materials`: движок
рисует по полю `shader` (`mesh`, `shield`). Новые шейдеры добавляются кодом,
а сами материалы и их параметры правятся без правок движка.
