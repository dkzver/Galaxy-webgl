# Правило: как сделать меш щита

Документ обязателен для любого щита корабля: он описывает, каким должен быть
меш, коллайдер и данные сцены, чтобы работали локальное гексагональное пятно в месте
удара.

## 1. Геометрия

- Щит — **отдельный меш-оболочка**, не сливать с корпусом и не красить корпус.
- Габариты чуть больше корпуса: зазор 0.1–0.3 м по каждой оси. Ориентир для
  Corinth: корпус `3.88 × 2.32 × 6.71`, щит после масштабирования ×1.08 —
  `4.63 × 2.94 × 7.68`, радиус `4.19`.
- Origin — в центре корабля, нос в **−Z**, верх **+Y**, масштаб **1**.
  Масштаб не 1 допустим, но коллайдер в сцене тогда умножается на него.
- Нормали — наружу. Внутренние стенки, двойные поверхности и толщина не нужны:
  щит рисуется аддитивно, важна только внешняя сторона.
- Одна группа / один материал. UV и текстуры не нужны — шейдер `shield`
  их игнорирует.

## 2. Ассет модели

- id: `<корабль>-shield`, например `corinth-cargo-transported-shield`.
- Файлы: `public/models/<id>.json` + `<id>.mesh.bin`.
- `radius` в манифесте — максимальное расстояние вершины от origin
  (у Corinth — `3.55`).
- Импорт: редактор модели → «Импорт GLB» (или сборщик). После использования
  в сценах id не менять — сломаются ссылки.
- Программно изменить размер без новых моделей:
  `node tools/model-scale.mjs <id> <factor>` — перезаписывает тот же
  `<id>.json` и `<id>.mesh.bin`, пересчитывает габариты, длину и радиус.
  Так щит был увеличен ×1.08 без появления `…-shield-2`.

## 3. Коллайдер

- Тип тела `static`, форма `sphere` (или compound, если нужна точность).
- Коллайдер **обязан быть снаружи корпуса**: радиус ≥ максимального полуразмера
  корпуса + 0.2–0.5 м. Для Corinth после масштабирования — **4.2**; исходные
  3.55 были внутри коллайдера корпуса, и снаряды били корпус, а не щит.
- Тело должно построиться. Поэтому **нельзя** ставить `"visible": false`
  в данных сцены: `scene-runtime` в этом случае не создаёт ни меш, ни тело.

## 4. Данные сцены или префаба

```json
{
  "id": "corinth-cargo-transported-shield-1",
  "type": "model",
  "name": "corinth_cargo_transported_shield",
  "asset": "corinth-cargo-transported-shield",
  "materialId": "shield",
  "body": {
    "kind": "static",
    "collider": { "shape": "sphere", "radius": 4.8 }
  },
  "scripts": ["ship/shield.js"]
}
```

- `materialId: "shield"` — оболочку рисует материал. Без него скрипт
  `ship/shield.js` работает в старом режиме: прячет меш, оставляя коллайдер.
- `scripts: ["ship/shield.js"]` — копит попадания в `entity.shieldHits`.
- `visible` не выключать. `hiddenParts` на сам щит не вешать.

## 5. Материал

`public/materials/shield.material.json`:

| Параметр | Смысл |
|---|---|
| `color` | цвет оболочки (по умолчанию `#59d8ff`) |
| `hitColor` | цвет попадания (`#eaffff`) |
| `base` | базовая прозрачность оболочки, 0.02–0.08 |
| `fresnel` | степень френеля: больше — тоньше кромка |
| `hitRadius` | радиус пятна, м |
| `hexScale` | масштаб гексагональной сетки |
| `patchLife` | сколько живёт пятно, с |

Цвет оболочки и цвет попадания раздельны: пятно должно читаться на фоне
кромки. Правки — в JSON или в окне материала.

## 6. Проверка

1. Редактор сцены: у сущности щита выбран материал `shield`.
2. Игра: вне попаданий щит не виден; в точке удара появляется локальное
   гексагональное пятно с волной непрозрачности (без волны по всей оболочке).
3. **F3**: сфера коллайдера щита снаружи корпуса.
4. Попадание: в консоли `__galaxy.entities.find(e => e.id === '…-shield-1').
   shieldHits.length` растёт; на корпусе вспыхивает гексагональное пятно.
5. `npm test` — зелёный.

## 7. Частые ошибки

| Ошибка | Что происходит |
|---|---|
| `visible: false` в данных | сущность не строится, коллайдера нет |
| коллайдер внутри корпуса | попадания не доходят до щита, события нет |
| меш слит с корпусом | щит нельзя скрыть/заменить, пятно конфликтует с обшивкой |
| несколько групп с разными материалами | рисуются одинаково шейдером щита, текстуры игнорируются |
| масштаб ≠ 1 | радиус коллайдера в сцене умножается на масштаб |
| забыт `materialId` | меш скрыт, видна только кромка? нет — щит невидим |

## 8. Чек-лист готовности

- [ ] меш-оболочка с зазором 0.1–0.3 м, нормали наружу
- [ ] id `<корабль>-shield`, файлы json + mesh.bin
- [ ] коллайдер снаружи корпуса (радиус с запасом)
- [ ] `materialId: "shield"` и скрипт `ship/shield.js`
- [ ] материал настроен, цвета оболочки и попадания разные
- [ ] проверено попадание и `npm test`
