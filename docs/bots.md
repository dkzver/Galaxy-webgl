# Боты: зрение и атака

Префаб `public/prefabs/bot.json` — пустой корень с мешем `spaceship` и скриптом
`bots/aim-attack.js`. Скрипт сам находит игрока, наводится и стреляет; движок
про ботов ничего не знает и только крутит скрипты сцены.

## Как работает

1. **Обзор.** Каждый кадр бот проверяет, попадает ли игрок в конус:
   расстояние `range` и угол `fovDeg`. Пока игрок вне конуса, корпус медленно
   сканирует пространство (`scanRate`).
2. **Захват.** Первый контакт рассылает событие `bot.contact`. Соседи в радиусе
   `squadRange` запоминают точку на `squadMemory` секунд и доворачиваются к ней,
   но стреляют только по собственному контакту — чужих целей не видят.
3. **Наведение.** После захвата ограничение конуса снимается: корпус доворачивается
   к игроку в любую сторону со скоростью `turnRate`. Точка прицела считается
   с упреждением по скорости игрока (`lead`, `projectileSpeed`).
4. **Огонь.** Раз в `fireInterval` секунд, если ошибка наведения меньше
   `aimToleranceDeg`, бот выпускает снаряд через `ctx.api.projectiles.fire`.
   Снаряд — обычный префаб с блоком `projectile` (по умолчанию `rocket`),
   поэтому попадание считает свип, а импульс получает тело цели.
5. **Потеря цели.** Если игрок вышел из конуса, бот ещё `loseGrace` секунд
   держит захват и продолжает наводиться, затем возвращается к сканированию.

## Параметры скрипта

| Параметр | По умолчанию | Что задаёт |
|---|---|---|
| `range` | 180 | дальность обзора, м |
| `fovDeg` | 140 | полный угол конуса обзора, ° |
| `turnRate` | 1.6 | скорость наведения, рад/с |
| `scanRate` | 0.4 | скорость сканирования, рад/с |
| `fireInterval` | 2.6 | интервал между выстрелами, с |
| `aimToleranceDeg` | 14 | допустимая ошибка наведения для выстрела, ° |
| `projectile` | `rocket` | id префаба снаряда |
| `projectileSpeed` | 120 | скорость снаряда, м/с |
| `projectileLife` | 5 | жизнь снаряда, с |
| `muzzleOffset` | 5 | вынос дула вперёд от центра, м |
| `lead` | 0.8 | доля полного упреждения, 0…1 |
| `loseGrace` | 3 | сколько секунд держать цель вне конуса |
| `squadRange` | 400 | радиус оповещения соседей, м |
| `squadMemory` | 4 | сколько секунд помнить контакт соседа |

Все параметры правятся в инспекторе редактора в секции «Скрипты».

## Как поставить бота

1. В редакторе: выберите префаб **«Бот»** → **«Вставить»**, поставьте в точку и
   сохраните сцену.
2. Или добавьте в сцену пустой узел со скриптом:

```json
{
  "id": "bot-1",
  "type": "empty",
  "name": "Бот",
  "position": [45, 8, -70],
  "scripts": [{ "file": "bots/aim-attack.js" }],
  "tags": ["bot"],
  "children": [
    { "id": "bot-1-mesh", "type": "model", "asset": "spaceship", "body": { "kind": "static", "collider": { "shape": "sphere", "radius": 4.5 } } }
  ]
}
```

Демо: `http://localhost:3000/?scene=bots-demo` — два бота рядом с игроком.

## Ограничения

- **Урона по HP нет**: атака — это импульс телу игрока (40 в префабе `rocket`).
  Полоски здоровья и разрушения ботов появятся вместе с системой HP.
- **Линия видимости не проверяется**: стены и станции не мешают обнаружению.
  Для честной проверки нужен рейкаст по телам — его можно добавить в
  `projectiles.js` как отдельную функцию.
- **Стрельба требует пула снарядов**: без `ctx.api.projectiles` (например, в
  редакторе) бот наводится, но не стреляет.
- Боты статичны: они не летают, а работают как турели. Для патрулирования есть
  отдельный скрипт `bots/patrol.js` — его можно комбинировать с наведением.
