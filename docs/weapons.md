# Оружие GalaxyDemo

Три слота, три отдельных скрипта на объекте «Оружие» в префабе игрока:

| Слот | Клавиша | Оружие | Скрипт | Режим |
|------|---------|--------|--------|-------|
| 1 | **1** | Лазерная указка | [`weapons/laser.js`](../public/scripts/weapons/laser.js) | `hold` |
| 2 | **2** | Пулемёт | [`weapons/machinegun.js`](../public/scripts/weapons/machinegun.js) | `burst` |
| 3 | **3** | Ракета | [`weapons/rocket.js`](../public/scripts/weapons/rocket.js) | `single` |

Панель — [`public/scripts/weapons.js`](../public/scripts/weapons.js), HUD —
[`public/hud/weapons.html`](../public/hud/weapons.html). Общая логика точек вылета и
прицела — [`weapons/muzzles.js`](../public/scripts/weapons/muzzles.js).

Панель **только рисует**: берёт `weapons.slots` и `weapons.status` и обновляет
активный слот и строку статуса. Она ничего не читает и не пишет в общее состояние.

Ввод живёт в контроллере —
[`weapons/controller.js`](../public/scripts/weapons/controller.js). Он **единственное
место, где читаются клавиши 1–3, клики по слотам HUD и ЛКМ**: выбирает оружие,
проверяет статусы и отправляет `weapon.trigger` (`down: true/false`) нужному
скрипту. Скрипты оружия ввод не читают.

Пока другое оружие ещё отрабатывает (`busy: true`, например очередь пулемёта),
контроллер не даёт стрелять новому. У выбранного оружия также не должно быть
незаконченной очереди или перезарядки.

---

## 1. Быстрый старт

1. `npm start`, открыть <http://localhost:3000>.
2. **1**, **2** или **3** — выбрать оружие (или клик по слоту в панели «ОРУЖИЕ»).
3. **ЛКМ**:
   * указка — луч горит, пока кнопка нажата (press/release от контроллера);
   * пулемёт — один клик запускает очередь;
   * ракета — один пуск.
   Пока предыдущее оружие не отработало, новое не стреляет.
4. **Esc** — пауза, стрельба блокируется. **СКМ** — обзор камеры.

---

## 2. Точка вылета

Задаётся в инспекторе: `muzzle1…muzzle4` (тип «entity»). Пустые значения
отбрасываются, порядок сохраняется.

* каждое новое нажатие (указка) или каждый выстрел (пулемёт, ракета) берёт
  следующую точку по кругу: 1-я → 2-я → … → снова 1-я;
* **мировая позиция ствола не запоминается**: указка читает её каждый кадр,
  снаряды — в момент выстрела. Ствол — ребёнок корабля, поэтому эффект едет
  вместе с корпусом и не «отстаёт» в поворотах;
* точек нет — вылет из точки в 5 единицах перед носом корабля.

Корпус перекрывает луч и трассеры: эффекты рисуются с проверкой глубины, поэтому
видимая часть начинается там, где снаряд выходит из габаритов корабля.

---

## 3. Точка прицела

Одна для всех оружий: мировая точка в 500 единицах от носа вдоль оси корабля
(`нос + forward × 500`, константа `TARGET_DISTANCE` в `public/js/main.js`).
Корабль автоматически доворачивается, чтобы она была в центре кадра.

В режиме обзора (СКМ) автонаведение отключено. Перекрестие меняет цвет, если
линия до цели упирается в модель ([`target.js`](../public/scripts/target.js));
на выстрел это не влияет.

## 4. Оружие

### 4.1. Лазерная указка — клавиша 1

* **Режим:** `hold` — луч горит, пока ЛКМ нажата.
* **Точка вылета:** пересчитывается каждый кадр.
* **Луч:** от ствола до точки прицела, `ttl` 0.06 с (обновляется каждый кадр).
* **Параметры:** `targetDistance` 500, `width` 8, `intensity` 2.4.
* **Перезарядка:** нет.

### 4.2. Пулемёт — клавиша 2

* **Режим:** `burst` — один клик запускает очередь.
* **Очередь:** 25 выстрелов, интервал 0.2 с, первый — сразу.
* **Перезарядка:** 0.8 с после последнего выстрела.
* **Трассер:** скорость 650 ед/с, жизнь 1.2 с, дымный след, искра в точке прицела.
* **Точка вылета:** читается заново на каждый выстрел, стволы чередуются.
* Отпускание ЛКМ очередь не останавливает; смена слота отменяет остаток.

### 4.3. Ракета — клавиша 3

* **Режим:** `single` — один пуск на нажатие.
* **Перезарядка:** 1.4 с.
* **Снаряд:** сущность из префаба `rocket` через `api.projectiles.fire()`,
  скорость 95 ед/с, жизнь 6 с, без наведения.
* **Попадание:** свип сферы по телам сцены, импульс и `projectile.hit`.
* **Точка пуска:** читается заново на каждый пуск, `gun-left` / `gun-right`.

Урона и здоровья пока нет: оружие создаёт эффекты и события (`weapon.fire`,
`projectile.hit`), но не уменьшает HP.

## 5. HUD и статусы

```text
ОРУЖИЕ                                      ГОТОВ
[1 УКАЗАТЕЛЬ] [2 ПУЛЕМЁТ] [3 РАКЕТА]
```

| Статус | Когда |
|--------|-------|
| `ГОТОВ` | оружие можно применять |
| `ЛУЧ АКТИВЕН` | указка удерживается |
| `ОЧЕРЕДЬ N/25` | пулемётная очередь в процессе |
| `ПЕРЕЗАРЯДКА X.X С` | перезарядка пулемёта или ракеты |

Перезарядка считается отдельно для каждого оружия и не сбрасывается при
переключении. Активный слот подсвечен.

## 6. Файлы

| Файл | Назначение |
|------|------------|
| `public/scripts/weapons.js` | панель: только отрисовка слотов и строки статуса |
| `public/scripts/weapons/controller.js` | ввод: клавиши 1–3, клики по слотам HUD, ЛКМ; выбор и press/release |
| `public/scripts/weapons/muzzles.js` | общие точки вылета и прицела для всех оружий |
| `public/scripts/weapons/laser.js` | лазерная указка |
| `public/scripts/weapons/machinegun.js` | пулемёт, трассеры, дым |
| `public/scripts/weapons/rocket.js` | пуск ракеты через префаб |
| `public/hud/weapons.html` | разметка панели |
| `public/js/effects.js` | отрисовка лучей, трассеров, дыма, искр |
| `public/js/projectiles.js` | полёт и свип-попадания ракеты |

Скрипты оружия — обычные сценарные модули: `export const params`, `init`,
`update`, `dispose`; DOM и WebGL они не трогают.

## 7. Как настроить или добавить оружие

1. Параметры слота — в массиве `WEAPONS`
   (`public/scripts/weapons/controller.js`): `id`, `key`, `name`, `mode`, `statusKey`.
2. Клавиши — в `KEY_SLOTS` там же.
3. Параметры стрельбы — в `params` соответствующего скрипта или в префабе.
4. Новый слот: добавить запись в `WEAPONS`, кнопку `weapon-slot-N` в HUD и
   скрипт на объект «Оружие» в префабе/сцене. Контроллер сам зарегистрирует
   клик по кнопке и клавишу.

---

## 8. Отладка

```js
__galaxy.scripts.instances                 // все скрипты сцены
__galaxy.projectiles.stats()               // пул и попадания ракет
window.__laserDebug                        // состояние указки
```

В консоли удобно смотреть `weapons.status` через `ctx.api.shared` любого
экземпляра контроллера.

## 9. Тесты

```powershell
npm test
```

Проверяются: три слота и клавиши 1–3, статусы очереди и перезарядки, удержание
и отпускание луча, чтение точки вылета на каждый кадр/выстрел, очередь
пулемёта, пуск и перезарядка ракеты, физика снарядов.
